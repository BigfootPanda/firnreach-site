The default keys. Every one can be rebound in **Settings**, and **Esc** always opens the pause menu.
Press **H** in a match to show or hide the controls panel.

## General

<div class="wrap-table">

| Action | Key |
|---|---|
| Pause menu (Esc always works too) | **P** |
| Switch first person / commander | **Tab** |
| Build mode / build bar | **B** |
| Show / hide the controls panel | **H** |
| Chat | **Enter** |
| Ping: tap = mark what you aim at, hold = ping wheel | **Middle Mouse** |
| Taunt (Tank role): nearby enemies attack you | **C** |
| Auto-power on / off | **V** |
| Call a Frost Surge | **K** |
| Skip the day (start the next wave now) | **J** |
| Vote yes (team votes) | **Y** |
| Vote no (team votes) | **N** |
| Base menu (player upgrades) | **Home** |
| Deposit all your crystals in the team Bank (facing it / Bank selected) | **Z** |
| Mine the objective crystal | **M** |
| Rotate tower / respawn when down | **R** |
| Upgrade the selected tower | **U** |
| Sell the selected tower | **X** |

</div>
